# Europe Business Lead Finder

React + Vite app.

## Local run
```
npm install
npm run dev
```

## Vercel deploy
1. Folder ko GitHub repo mein push karo (ya `vercel` CLI use karo).
2. Vercel > Add New Project > repo select karo.
3. Framework: Vite (auto-detect). Build: `npm run build`, Output: `dist`.
4. Deploy.
